📌 AŞAMA 1: BIOS & DONANIM AYARLARI
--------------------------------------------------------------------------------
[ ] 1.1. Resizable BAR (ReBAR / SAM)
    • Bilgisayarı açarken DEL veya F2 tuşuna basarak BIOS'a girin.
    • Advanced veya PCIe Configuration menüsüne gidin.
    • Above 4G Decoding ➔ Enabled yapın.
    • Re-Size BAR Support ➔ Auto veya Enabled yapın.
    • F10 tuşuna basarak ayarları kaydedip çıkın.

[ ] 1.2. XMP / DOCP (RAM Frekansı)
    • Görev Yöneticisi > Performans > Bellek sekmesinden RAM MHz değerinizi kontrol edin.
    • RAM orijinal hızında çalışmıyorsa BIOS'a girip XMP (DOCP / EXPO) ayarını aktifleştirin.


📌 AŞAMA 2: WINDOWS İÇİ MANUEL AYARLAR
--------------------------------------------------------------------------------
[ ] 2.1. Monitör Yenileme Hızı (Hz)
    • Ayarlar > Sistem > Ekran > Gelişmiş görüntü ayarları yolunu izleyin.
    • Monitörünüzün desteklediği en yüksek Hz değerini seçin.

[ ] 2.2. Sistem Görsel Efektleri (sysdm.cpl)
    • Win + R tuşlarına basıp "sysdm.cpl" yazın ve Enter'a basın.
    • Gelişmiş > Performans > Ayarlar sekmesine gidin.
    • "En iyi performans için ayarla" seçeneğini seçin.
    • Görselliği korumak için SADECE şu iki kutuyu işaretleyin:
      [x] Ekran yazı tipi kenarlarını düzelt
      [x] Simgeler yerine küçük resimler göster

[ ] 2.3. Görev Yöneticisi Başlangıç
    • Ctrl + Shift + Esc ile Görev Yöneticisi'ni açın.
    • Başlangıç sekmesinden Discord dahil gereksiz tüm uygulamaları devre dışı bırakın.

[ ] 2.4. Grafik Performans Tercihi
    • Ayarlar > Sistem > Ekran > Grafik Ayarları menüsüne gidin.
    • "Göz at" butonuna basarak oynadığınız oyunların .exe dosyalarını ekleyin.
    • Eklenen oyunların üzerine tıklayıp Seçenekler > "Yüksek Performans" seçin.

[ ] 2.5. Ekran Kartı Sürücüsü
    • Ekran kartı sürücünüzü kendi resmi sitesinden (NVIDIA / AMD / Intel) indirip güncel tutun.
    • Asla 3. parti sürücü bulucu programlar kullanmayın.

📌 PHASE 1: BIOS & HARDWARE SETTINGS
--------------------------------------------------------------------------------
[ ] 1.1. Resizable BAR (ReBAR / SAM)
    • Restart your PC and press DEL or F2 to enter BIOS.
    • Go to Advanced or PCIe Configuration menu.
    • Set Above 4G Decoding ➔ Enabled.
    • Set Re-Size BAR Support ➔ Auto or Enabled.
    • Press F10 to save and exit.

[ ] 1.2. XMP / DOCP (RAM Frequency)
    • Check your RAM MHz value via Task Manager > Performance > Memory.
    • If your RAM is not running at its original speed, enter BIOS and enable XMP (DOCP / EXPO).


📌 PHASE 2: WINDOWS MANUAL SETTINGS
--------------------------------------------------------------------------------
[ ] 2.1. Monitor Refresh Rate (Hz)
    • Go to Settings > System > Display > Advanced display settings.
    • Select the highest supported Hz value for your monitor.

[ ] 2.2. System Visual Effects (sysdm.cpl)
    • Press Win + R, type "sysdm.cpl" and press Enter.
    • Go to Advanced > Performance > Settings.
    • Select "Adjust for best performance".
    • To keep visual clarity, ONLY check these two boxes:
      [x] Smooth edges of screen fonts
      [x] Show thumbnails instead of icons

[ ] 2.3. Task Manager Startup
    • Open Task Manager with Ctrl + Shift + Esc.
    • Disable unnecessary apps (including Discord) from the Startup tab.

[ ] 2.4. Graphics Performance Preference
    • Go to Settings > System > Display > Graphics settings.
    • Click "Browse" and add the .exe files of the games you play.
    • Click on the added games, select Options > "High Performance".

[ ] 2.5. Graphics Card Driver
    • Download and update your graphics driver from its official website (NVIDIA / AMD / Intel).
    • Never use 3rd-party driver booster software.
